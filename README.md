# ระบบจัดการคลังสินค้า

แอป Python 3.12+ และ Flet สำหรับเพิ่ม แก้ไข ลบ ค้นหา และติดตามสต็อกสินค้า

## เริ่มใช้งาน

ติดตั้ง dependencies ตาม `pyproject.toml` แล้วรัน:

```powershell
python main.py
```

หากต้องการให้โปรแกรมโหลดโค้ดใหม่อัตโนมัติ ให้ใช้:

```powershell
.\run.ps1
```

ฐานข้อมูลเก็บนอกโปรเจกต์เพื่อไม่ให้การบันทึกกระตุ้น hot reload แม้ใช้ `flet run --recursive main.py` ส่วน `run.ps1` ยังช่วยยกเว้นแคชและไฟล์ข้อมูลเก่า

## การใช้งาน

### บัญชีสำหรับสาธิต

มีบทบาทเดียวคือ **ผู้ดูแลคลัง** เข้าสู่ระบบด้วย `owner` / `Owner@2026` (แยกตัวพิมพ์ใหญ่–เล็ก)
สำหรับพรีเซน กด **เข้าระบบผู้ดูแลคลัง (สาธิต)** บนหน้า Login ได้ทันที ปุ่มใช้บัญชีและรหัสผ่านสาธิตข้างต้นผ่านการตรวจสอบ Login ตามปกติ
ผู้ดูแลเพิ่ม แก้ไข ลบสินค้า รับเข้า–เบิกออก และดูประวัติทั้งหมดได้ รหัสผ่านเก็บเป็น PBKDF2 hash พร้อม salt
บัญชีเจ้าของคลังเดิมใช้ชื่อผู้ใช้และรหัสผ่านเดิมได้ บัญชีพนักงานเดิมถูกปิดใช้งาน แต่เก็บสินค้าและประวัติผู้ทำรายการทั้งหมดไว้
ปุ่มออกจากระบบยกเลิก session และกลับหน้า Login

- รหัสสินค้าเป็นอัตโนมัติ เช่น `P008` โดยสร้างเมื่อบันทึกสำเร็จเท่านั้น การยกเลิกหรือบันทึกล้มเหลวไม่ใช้เลขลำดับ
- รหัสที่ลบแล้วจะไม่ถูกนำกลับมาใช้ และไม่สามารถเปลี่ยนรหัสในฟอร์มแก้ไขได้ ประวัติสต็อกยังอ้างอิงรหัสเดิม
- เมื่ออัปเกรด ระบบคงรหัสสินค้าเดิมและเริ่มลำดับถัดจากรหัส `P` ตามด้วยตัวเลขที่สูงที่สุดในรายการสินค้าและประวัติที่มีอยู่
- ค้นหาด้วยรหัส ชื่อ หรือหมวดหมู่ พร้อมกรองหมวดหมู่และสถานะร่วมกัน
- คลิกการ์ดสินค้าที่ต้องเติมเพื่อดูทั้งสินค้าใกล้หมดและหมดแล้ว หรือกดแสดงทั้งหมดเพื่อล้างตัวกรอง
- กดปุ่มลูกศรเข้า–ออกในแถวสินค้าเพื่อรับเข้า/เบิกออก โดยระบุจำนวนและเหตุผล
- เลื่อนรายการภายในตารางได้โดยหัวคอลัมน์ยังอยู่ และเลื่อนแนวนอนได้เมื่อหน้าต่างแคบ
- ประวัติสต็อกแสดง 200 รายการล่าสุด รวมการปรับจำนวนจากฟอร์มและการลบสินค้า
- สถานะหมดคือ 0 ชิ้น ใกล้หมดคือ 1–9 ชิ้น และพร้อมขายคือ 10 ชิ้นขึ้นไป
- มูลค่ารวมใช้ราคาต่อหน่วยที่กรอกคูณจำนวนคงเหลือ ไม่แยกต้นทุนกับราคาขาย

## ข้อมูล

ข้อมูลบันทึกใน SQLite ที่ `%LOCALAPPDATA%/Inventory-Management-System/inventory.db` บน Windows เมื่อเปิดรุ่นนี้ครั้งแรก ระบบคัดลอกฐานข้อมูลเดิมจาก `FLET_APP_STORAGE_DATA` หรือ `.flet/storage/data` หรือ `storage` ตามลำดับ โดยเก็บต้นฉบับไว้ หากปลายทางมีข้อมูลแล้วจะไม่คัดลอกทับ ข้อมูลตัวอย่างสร้างเฉพาะฐานข้อมูลใหม่เท่านั้น

ข้อมูลจากโปรแกรมรุ่นเดิมที่เก็บในหน่วยความจำไม่ได้ถูกย้ายเข้าฐานข้อมูลโดยอัตโนมัติ
